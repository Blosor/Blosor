# Blosor (✷) — 3D Game Engine & Creation Platform

**Blosor** adalah platform pembuatan dan permainan game 3D berbasis web yang memungkinkan pengguna membuat, mengembangkan, dan memainkan game langsung di browser tanpa harus memasang aplikasi editor khusus.

Blosor dirancang untuk menyatukan konsep **Game Engine**, **Game Studio**, dan **Game Platform** dalam satu ekosistem yang ringan dan mudah diakses.

- **Website Resmi:** https://blosor.github.io/Blosor/
- **Repository Resmi:** https://github.com/Blosor/Blosor
- **Developer:** Blosor

---

## 1. Apa Itu Blosor?

Blosor dirancang agar pengguna dapat melakukan dua hal utama langsung dari browser:

- **Membuat Game:** Membangun dunia 3D, mengatur objek, menyusun mekanisme permainan, serta menguji hasil karya melalui **Blosor Studio** bawaan.
- **Memainkan Game:** Menjelajahi dan memainkan berbagai game yang dibuat menggunakan Blosor.

---

## 2. Fitur Utama

- **✷ 3D Engine:** Mesin utama untuk me-render dunia dan objek 3D serta menangani interaksi di dalam game.
- **✷ Blosor Studio:** Editor bawaan untuk membuat dan mengatur dunia game tanpa memerlukan aplikasi editor eksternal.
- **✷ Scripting System:** Sistem skrip untuk mengatur perilaku objek, logika permainan, dan interaksi antar-elemen.
- **✷ Multiplayer:** Dukungan bermain bersama pemain lain melalui koneksi *multiplayer* berbasis P2P.
- **✷ Browser-Based Platform:** Berjalan langsung di browser sehingga praktis diakses tanpa instalasi aplikasi *desktop* khusus.
